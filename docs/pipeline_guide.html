Idempotency

The ingestion script guards against duplicate loads. Before inserting a year's data it compares the incoming row count against what is already in the table for that year:

  • Row counts match → skip, no action taken
  • Row counts differ → delete that year's rows, re-insert
  • Year not present → insert directly

Columns added in later CDC releases (not present when the table was first created) are automatically added with ALTER TABLE ... ADD COLUMN IF NOT EXISTS TEXT before the append.

Why half the rows are dropped: CDC PLACES publishes each measure twice — once as age-adjusted prevalence (AgeAdjPrv) and once as crude prevalence (CrdPrv). Staging keeps only AgeAdjPrv so downstream models don't need to filter or accidentally double-count.

  • Year cast: TEXT → INTEGER
  • data_value cast: TEXT → NUMERIC

  • population cast: totalpopulation → INTEGER
  • Column renames: stateabbr → state_abbr, statedesc → state_name, locationname → county_name, measureid → measure_id, etc.
  • Null filter: rows with data_value IS NULL removed
  • Data value type filter: keep datavaluetypeid = 'AgeAdjPrv' only

stg_epa_pm25

dbt/models/staging/stg_epa_pm25.sql  ·  materialized as view

Constructs county FIPS from state and county codes, renames and types the columns needed for downstream aggregation, drops the 40+ columns not used in the analysis, and removes stations with insufficient observation coverage.

Coverage filter: stations where Observation Percent < 75 are removed. EPA guidance defines 75% valid observations as the minimum threshold for a representative annual mean. Removing low-coverage stations prevents sparse or malfunctioning monitors from distorting the county-level aggregation in the intermediate layer.

Transformations

  • FIPS construction: lpad("State Code", 2, '0') || lpad("County Code", 3, '0') — produces standard 5-digit FIPS
  • Column renames: all space-separated EPA names → snake_case (e.g. Arithmetic Mean → arithmetic_mean)
  • Type casts: Year → INTEGER, Arithmetic Mean → NUMERIC, Observation Count → INTEGER, Observation Percent → NUMERIC, Latitude/Longitude → NUMERIC
  • Coverage filter: obs_pct < 75 rows removed (~12% of rows)
  • Null filter: rows with Arithmetic Mean IS NULL removed
  • 40 columns dropped: percentile distributions, exceedance counts, max-value timestamps, method name, datum, site address, CBSA name, etc.

Output schema

Grain: one row per monitoring station × year × parameter. Still station-level — aggregation to county happens in the intermediate layer.

Step 1 — Aggregate EPA to county-year

The EPA staging table is station-level. Many counties have multiple monitors. Before joining to PLACES (which is county-level), stations are grouped to a single county-year mean: 

SELECT
    county_fips,
    year,
    avg(arithmetic_mean)  AS pm25_annual_mean,
    count(*)              AS station_count,
    avg(obs_pct)          AS avg_obs_pct
FROM stg_epa_pm25
GROUP BY county_fips, year
Note: This CTE aggregates across all three parameters (PM2.5, Ozone, NO2) unless filtered. The mart currently uses pm25_annual_mean as the primary exposure. If you need parameter-specific county means, add a WHERE parameter_code = 88101 filter before aggregating.

Step 2 — Left join to PLACES

PLACES is the left table. EPA county-year means are joined on county_fips + year. Counties with no EPA monitor coverage keep their PLACES rows and receive NULL for PM2.5 columns; the missing_pm25 flag is set to TRUE for these rows. 

LEFT JOIN pm25_county_year e
ON  p.county_fips = e.county_fips
AND p.year        = e.year

Columns added by this layer

pm25_annual_mean pm25_station_count pm25_avg_coverage missing_pm25 (boolean)
Coverage note: Only 27.6% of county-year rows in the mart have PM2.5 data. Not every county has an EPA monitoring station — rural and frontier counties are disproportionately unmonitored. The missing_pm25 flag is the correct way to handle this in analysis; do not treat NULL PM2.5 as zero.

Pivot pattern

The long-to-wide transformation uses conditional aggregation on measure_id. Each outcome column is a MAX(CASE WHEN ...) expression: 

max(case when measure_id = 'OBESITY'   then data_value end) as obesity_pct,
max(case when measure_id = 'DIABETES'  then data_value end) as diabetes_pct,
max(case when measure_id = 'CASTHMA'   then data_value end) as asthma_pct,
-- ...
GROUP BY county_fips, state_abbr, state_name, county_name, year,
         population_count, pm25_annual_mean, pm25_station_count,
         pm25_avg_coverage, missing_pm25

Year Coverage

CDC PLACES and EPA AQS have different release cadences. Understanding which measures are available in which years is essential for exposure-outcome analysis.

PLACES release cycle

CDC PLACES alternates which measures it publishes each release cycle. Core chronic disease measures appear in odd years; preventive screening measures appear in even years.
